We use foreach because:

It simplifies looping through arrays.
You don't need to count elements like in for loop.
It automatically accesses each element.
It reduces chances of index errors.
Code becomes cleaner and easier to read.

Example situation:

You have a list of students
You want to print each student's name.

Instead of manually writing indexes, foreach handles it automatically.

# syntax of foreach
foreach($array as $value){
    // code to execute
}
